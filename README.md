# 🏋️ FitLog — Workout Library & Gym Companion

**FitLog** is a dark, no-nonsense gym companion web application built with Next.js App Router, Tailwind CSS, and daisyUI. It allows fitness enthusiasts to browse lifts across major muscle groups, inspect details, manage today's workout plans (capped at 5 lifts), and track saved items with live metrics.

---

## 🚀 Technologies Used

- **Next.js (App Router)**: For server-side rendering, routing, and fast page navigation.
- **Tailwind CSS & daisyUI**: For responsive styling, sleek dark-mode aesthetics, and custom UI components.
- **React Context API**: For lightweight global state management without using `useEffect`.
- **Lucide React**: For clean, modern iconography.
- **React Hot Toast**: For interactive notifications and user feedback.

---

## ✨ Key Features

1. **Interactive Workout Library**: Displays workouts in a responsive 3x4 grid layout with category pills, equipment lines, duration, calories, and ratings.
2. **Dynamic Workout Details Page**: Comprehensive view featuring equipment specifications, difficulty levels, step-by-step instructions, and quick action buttons.
3. **Smart Plan & Save Management**: Add up to 5 lifts to "Today's Plan" or save items for later with live-updating navbar badge counters.
4. **Live Metrics Summary & Sorting**: Real-time calculation of total exercises, minutes, and calories on the plan page, complete with sorting options (Duration, Calories, Rating).
5. **Mark as Done & Progress Tracking**: Check off completed workouts in your daily plan with celebratory toast notifications.
